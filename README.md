# 北海道家族旅行のしおり（2026.8.16–20）

公開ページ: https://vbtaiki.github.io/kazoku/

4泊5日・6人の北海道家族旅行のしおりです。スマホでそのまま見られます。

## タブ構成

| タブ | 中身 |
|---|---|
| 🏠 ホーム | 出発までのカウントダウン、5日間のながれ、**まだ決まっていないこと**（予約TODO）、宿と車 |
| 📅 日程 | 1日ごとのタイムライン。「くわしく」で住所・電話・地図 |
| 👧 こども | ひらがなの写真図鑑。カードをタップすると施設の公式ページへ |
| 🍽 ごはん | 食事ごとに4つずつの候補（全8回・32店）。地図と電話つき |
| 🎒 持ち物・連絡先 | チェックリスト（端末に保存）と電話番号一覧 |

## 直接ひらけるリンク

`#home` `#days` `#kids` `#food` `#items` を付けると、そのタブが開いた状態で共有できます。
例: https://vbtaiki.github.io/kazoku/#food

## ファイル

- `index.html` … ページ本体（1ファイル完結）
- `images/` … 各施設・各社の公式サイトの写真（表示サイズに合わせて圧縮）
